# Recursos Clave

1.  *Plataforma de Software Base*
    * **Software Open Source (OSS):** Uso de sistemas de código abierto probados (como Odoo Community, Traccar, WordPress) que forman la capa de servicio para el cliente.
    * **Imágenes Maestras:** Plantillas optimizadas por Connectix que permiten el despliegue rápido y estandarizado de todos los servicios (ERP, Web, LDAP).
    * **Licencias de SO/Sistemas Operativos:** Sistemas operativos base (como Linux/Debian) para las Máquinas Virtuales y Contenedores.

2.  *Hardware Estándar y Soporte*
    * **Servidores y Hardware Estandarizado:** Adquisición de servidores mini-PC (tipo Intel NUC) o torres optimizadas con componentes específicos (RAM, discos duros) para asegurar rendimiento y fiabilidad 24/7.
    * **Almacenamiento Local (Discos):** Configuración de discos duros para RAID/ZFS dentro de Proxmox para garantizar la redundancia y la integridad de los datos del cliente.

3.  *Equipo Humano Especializado*
    * **Ingenieros de Sistemas:** Expertos en virtualización (Proxmox), redes (DNS, Firewall, VPN) y securización de servicios (LDAP, HTTPS).
    * **Soporte Técnico Remoto:** Personal dedicado a la monitorización proactiva de los servidores del cliente y resolución de incidencias.
    * **Consultores de Negocio:** Personal para la personalización inicial y la consultoría de optimización de los servicios (para planes Enterprise).

4.  *Propiedad Intelectual y Know-How*
    * **Protocolos de Despliegue:** Nuestro conocimiento interno de cómo integrar y securizar los servicios (como Nginx Reverse Proxy, certificados SSL) en el ecosistema Proxmox.
    * **Algoritmos de Monitorización:** Scripts y herramientas internas para la vigilancia remota de los servicios de los clientes.

5.  *Relaciones con Proveedores y Socios*
    * **Proveedores de Hardware:** Acuerdos para la adquisición de componentes con garantía y stock.
    * **Comunidades OSS:** Mantenimiento de relaciones con las comunidades de software libre (Odoo, Traccar) para estar al tanto de actualizaciones y vulnerabilidades.
    * **Soporte Cloud:** Acuerdo con proveedores de almacenamiento externo para las copias de seguridad de clientes Enterprise.
