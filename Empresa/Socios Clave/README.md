# Socios Clave

Para garantizar la implementación y el soporte continuo de nuestra solución "Connectix Hub", Connectix se apoya en los siguientes socios clave:

### 1. Proveedores de Hardware Estandarizado
* **Qué aportan:** Servidores Mini-PC, componentes de red y discos duros optimizados.
* **Por qué es clave:** Nos permiten estandarizar el "Connectix Hub", reducir los costes de ensamblaje y garantizar la compatibilidad del hardware con Proxmox.

### 2. Comunidades y Proveedores de Software Open Source (OSS)
* **Qué aportan:** El código base (Odoo, Traccar, etc.) y las actualizaciones necesarias para los servicios principales.
* **Por qué es clave:** Dependemos de estas comunidades para la funcionalidad, los parches de seguridad y para mantener nuestra Imagen Maestra de Proxmox actualizada, sin incurrir en costes de licencia.

### 3. Socio de Seguridad y Respaldo Remoto
* **Qué aporta:** Servicios de monitorización de amenazas y la infraestructura Cloud (ej. S3) necesaria para las copias de seguridad externas de los clientes Enterprise.
* **Por qué es clave:** Garantiza la seguridad del servidor local y la disponibilidad de los datos ante fallos físicos.

### 4. Socio de Consultoría Logística (Estratégico)
* **Qué aporta:** Asesoramiento experto para optimizar rutas, inventario y procesos operativos usando los datos que Connectix proporciona.
* **Por qué es clave:** Se reserva para los planes de servicio de alto valor (Enterprise), ayudando a los clientes a maximizar la eficiencia y justificar el coste del plan.
